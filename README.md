## Hello, Devs!! 👋
Frontend Developer specialized in **React and TypeScript**, focused on building scalable, maintainable, production-ready web applications — from the first wireframe to deployment and automated testing.

I have hands-on experience with:
- REST API integration and Backend as a Service (Supabase)
- JWT authentication, protected routes, and per-user data isolation
- Full CRUD with dedicated service layers
- Scalable architecture organized by **features** (authentication, domain, shared)
- Global state management with Hooks & Context API
- Automated testing with Vitest & React Testing Library (components, hooks, services, and utils)
