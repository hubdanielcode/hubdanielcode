## Hello, Devs!! 👋
Frontend Developer especializado em **React e TypeScript**, focado em construir aplicações web escaláveis, sustentáveis e prontas para produção — do primeiro wireframe até deploy e testes automatizados.

Tenho experiência prática com:
- Integração com REST APIs e Backend as a Service (Supabase)
- Autenticação JWT, rotas protegidas e isolamento de dados por usuário
- CRUD completo com camadas de services dedicadas
- Arquitetura escalável organizada por **features** (authentication, domínio, shared)
- Gerenciamento de estado global com Hooks & Context API
- Testes automatizados com Vitest & React Testing Library (componentes, hooks, services e utils)
- Visualização de dados com gráficos interativos (Recharts)
- Upload/recorte de imagens, temas claro/escuro e UI responsiva (desktop, mobile e landscape)

Priorizo **arquitetura limpa, type safety, performance e separação de responsabilidades** para criar codebases previsíveis e escaláveis — e cubro isso com testes desde os hooks até os fluxos de tela.

Atualmente evoluindo em direção a uma posição mid-level e expandindo para full-stack com Next.js.

## 🧩 Featured Projects

### 🤖 Codara AI
Plataforma de **análise inteligente de código** com IA, onde o usuário cola ou escreve código e recebe erros encontrados, sugestões, melhorias e código corrigido, com histórico de chats e sistema de patches.
- Autenticação JWT via Supabase com rotas protegidas
- Arquitetura por features (authentication, code-review, shared)
- Integração com Monaco Editor e upload/recorte de foto de perfil
- Tema claro/escuro e layout responsivo (desktop, mobile e landscape)
- Suíte de testes com Vitest + React Testing Library cobrindo contexts, hooks e services

🔗 Deploy: https://codara-ai.vercel.app/
🔗 Repositório: https://github.com/hubdanielcode/Codara-AI

### 🐾 PetMatch
Plataforma de **cadastro e adoção de pets**, com ficha de anamnese completa, feed com filtros, perfis de pets e tutores, avaliações por estrelas e comentários.
- Arquitetura por features (authentication, pet-registration, user-profile, shared)
- CRUD completo de pets e tutores com hooks customizados por domínio
- Sistema de avaliação e comentários integrado ao Supabase
- Badges dinâmicos por raça/características do pet
- Suíte de testes com Vitest + React Testing Library cobrindo hooks, pages e services

🔗 Deploy: https://pet-match-app-nine.vercel.app/
🔗 Repositório: https://github.com/hubdanielcode/PetMatch-App

### 💰 Finanzy
Dashboard de **gestão financeira pessoal**, com controle de receitas e despesas, saldo automático e gráficos interativos.

- Layout responsivo, incluindo suporte a mobile landscape
- Suíte de testes com Vitest + React Testing Library cobrindo componentes, hooks e utils
